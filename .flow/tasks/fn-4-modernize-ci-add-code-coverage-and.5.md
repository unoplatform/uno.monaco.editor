# fn-4-modernize-ci-add-code-coverage-and.5 Create .NET CLI tool for C# type emission from intermediate model

## Description
Create a .NET CLI tool that reads the intermediate JSON model from Task .4 and emits C# files matching existing patterns in `MonacoEditorComponent/Monaco/`.

**Size:** M
**Files:** `tools/MonacoTypeEmitter/` (new): `MonacoTypeEmitter.csproj`, `Program.cs`, emitter logic. Add to `MonacoEditorComponent.slnx`.

**Depends on:** Task .4 (intermediate JSON schema)

## Approach

- .NET console app (`OutputType=Exe`, `net10.0`)
- Read intermediate JSON via `System.Text.Json` deserialization
- Emit C# matching all existing patterns:
  - **String-backed enums:** `[JsonConverter(typeof(JsonStringEnumConverter<T>))]` + `[JsonStringEnumMemberName("value")]` + `[EnumMember(Value = "value")]`
  - **Numeric enums:** plain with integer values, no converter
  - **Model classes:** `public sealed class` with auto-properties, nullable for optional
  - **Interface types:** `[JsonConverter(typeof(InterfaceToClassConverter<IFoo, Foo>))]` pairing
  - **Namespace mapping:** `monaco.editor` -> `Monaco.Editor`, `monaco.languages` -> `Monaco.Languages`
  - **Constructor defaults:** Match `CompletionItem`-style primary constructor patterns where present
  - **Attribute omission policy:** No explicit `[JsonPropertyName]` when global CamelCase policy in `MonacoJsonContext` handles it; only emit when the JSON name differs from CamelCase of the C# name
- Deterministic file output ordering (same namespace/type order as JSON input)
- All emitted files get `// <auto-generated />` + `#nullable enable`

**`.generator-ignore` migration:**
- Migrate from filename-only matching to repo-relative path matching (e.g., `MonacoEditorComponent/Monaco/Editor/CompletionItem.cs`)
- Validate all protected files resolve uniquely; fail generation on ambiguous matches
- Load ignore list from config file in `tools/MonacoTypeEmitter/`

## Key context

- `MonacoJsonContext` uses global CamelCase + WhenWritingNull — emitter must conform
- 15 files in current `.generator-ignore` — these are hand-tuned and must never be overwritten
- The tool absorbs all 7 transforms from `postprocess-stj.ps1` — no separate post-processor
- Could use `PackAsTool` for NuGet distribution, but a simple console app is fine for internal use

Produces 573 deterministic C# files from the real Monaco 0.54.0 model.
