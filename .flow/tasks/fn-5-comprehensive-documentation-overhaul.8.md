## Description
Execute the XML documentation strategy chosen in task 6 for the ~40+ generated Monaco type files. Regenerate and validate all docs.

**Size:** M
**Files:** `MonacoEditorComponent/Monaco/Editor/*.cs`, `Monaco/Languages/*.cs`, `Monaco/Helpers/*.cs`, `Monaco/*.cs`, possibly emitter code if strategy A chosen

## Approach

Implementation depends on strategy chosen in task 6. Regardless of strategy:

- Core types needing thorough docs: `Position`, `Range`, `Selection`, `IPosition`, `IRange`, `Uri`, `IMarkdownString`
- Editor types: `StandaloneEditorConstructionOptions` (largest file), `IEditorOptions`, `IModelDeltaDecoration`, `Marker`, `MarkerData`
- Language types: `CompletionItem`, `CompletionList`, `CodeAction`, `Hover`, `TextEdit`, `WorkspaceEdit`, `Command`
- Provider interfaces: `HoverProvider`, `CompletionItemProvider`, `CodeActionProvider`, `CodeLensProvider`, `DocumentColorProvider`
- Enums (~35+): `MarkerSeverity`, `MarkerTag`, `SelectionDirection`, `CompletionItemKind`, etc.
- Use `<see href="..."/>` to cross-reference upstream Monaco TypeDoc API
- Mark generated files with `// <auto-generated />` header if not already present
- Consider `<inheritdoc/>` for interface → implementation relationships
